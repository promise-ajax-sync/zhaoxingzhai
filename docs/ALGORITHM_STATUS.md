## 当前算法阶段

当前处于“公共算法基础 + 两个样板术式”阶段，还没有进入全量算法迁移阶段。

- 公共随机、版本、结果协议和历史追踪已经具备。
- 小六壬和塔罗证明了算法到 UI、案例快照、历史记录的基本链路可以工作。
- 灵签与每日一卦已继续复用同一套算法、数据、UI、历史和案例快照流水线。
- 八字、紫微、奇门、六壬、星盘等复杂系统尚未开始，不能按导航入口数量估算算法完成度。

## 优先级原则

算法仍是产品核心，但现阶段不应以“尽快增加术式数量”为最高优先级。近期优先级应为：

1. 保证现有随机、历法、版本和向量测试跨平台稳定。
2. 清理小六壬、塔罗的结构和数据来源，使其成为可复制模板。
3. 用一个低风险查表型术式打通数据导出、加载、算法、UI、历史和 golden 测试全链路。
4. 流水线稳定后，再提高算法扩展速度。

复杂算法在上述基础未稳定前提前铺开，会放大版本、数据来源、历法口径和跨平台差异的返工成本。
